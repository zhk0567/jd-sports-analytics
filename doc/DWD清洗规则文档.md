# DWD 清洗规则文档

## 一、总原则

1. 先做外键有效性校验，再处理数值/时间/文本规则；
2. 每个事实表按业务主键去重；
3. 金额类字段统一转为数值，异常值丢弃；
4. 订单明细 GMV 按订单实付金额分摊，保证与订单事实对账；
5. 评价生成 sentiment，供商品口碑分析使用。

## 三、时间逻辑

- 支付时间 ≥ 下单时间；
- 发货时间 ≥ 下单时间；
- 送达时间 ≥ 发货时间；
- 签收时间 ≥ 送达时间；
- 退款时间 ≥ 支付时间。

不满足的记录在 DWD 层丢弃，并计入质量报告。
