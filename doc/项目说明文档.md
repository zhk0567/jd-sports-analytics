# 项目说明文档

## 一、项目定位

第2组运动品类电商经营分析平台：从 13 张 ODS 贴源表出发，经 6 张 DIM、10 张 DWD、18 张 DWS，落到 16 张 ADS，支撑 30 个核心指标、3 个 ML 模型、20 个 API 和 12 个图表大屏。

## 二、业务特征

- 男性为主（65.38%）；
- 品牌集中（Top5 销量占比 50.66%）；
- 客单价中高（1,112.10 元）；
- 618/双11 爆发明显（峰值日 79,511.56 元）；
- 季节性强（跑步/篮球/健身/户外/瑜伽场景）。

## 三、交付清单

| 类别 | 交付 |
|---|---|
| 数据 | 13 张 ODS CSV，24,935 行 |
| 数仓 | 6 DIM + 10 DWD + 18 DWS + 16 ADS |
| SQL | MySQL/Hive DDL，`sql/` |
| 调度 | `pipeline.ps1/.bat/.sh` |
| DataX | 26 导入 + 16 导出配置 |
| ML | 销售预测、流失预测、RFM |
| API | 20 个 `/api/t2/*` |
| 大屏 | `dashboard/dashboard_t2.html`，12 图表，30 秒刷新 |
| 文档 | 过程文档、字段字典、指标体系、质量/交叉验证、API、答辩 PPT |

## 四、运行

```powershell
.\pipeline.ps1
.venv\Scripts\python.exe -m flask --app flask_app.app run --port 5000
```

打开 <http://127.0.0.1:5000>。

## 五、核心结论

- GMV **2,135,906.30** 元，支付订单 **1,920** 单，客单价 **1,112.45** 元；
- 支付率 **98.16%**，复购率 **50.69%**，退货率 **8.8%**；
- 高价值 RFM 用户 **172** 人；
- 销售预测 LinearRegression：R² **0.7782**，MAPE **40.25%**；
- 流失模型 F1 **0.988**。
