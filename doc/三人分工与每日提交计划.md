### 共同约定

1. 每天开始先 `git pull`，提交前再 `git pull --rebase`，然后直接 push 到 `main`。
2. 每个人只改自己主责的文件；需要改别人的文件时，先在群里说一声，改完让对方 review。
3. 不提交 `.venv/`、`node_modules/`、数据库文件、模型二进制和大体量原始数据。
4. 每天至少 3 次有效提交，提交信息必须能看出模块和内容。
5. `doc/process/dayX.md` 由组长汇总，三个人当天的工作都要写进去。
6. 每天最后一个提交必须是“可运行状态”，不能把半成品留在 `main`。

2. Gitee 保持空仓库，不初始化 README。
3. 本地以 GitHub 当前内容为参考，但新建一个干净的 `t2_ecommerce` 工作目录。
4. 按 Day 1 → Day 4 顺序每天提交、每天 push，不一次性推完。
5. 每天检查 `git log --oneline --author=...`，确保三个人当天都有提交。
6. Day 4 最后再打 `v1.0.0`，不要在 Day 1~3 提前打 tag。

> 注意：本文只是计划。当前没有对 Gitee 做任何改名、提交或推送；GitHub 内容保持完整不动。
